# Assets — Avante

Ativos de marca e identidade visual, consumidos por frontend, mobile e materiais de comunicação.

## Estrutura sugerida

```
assets/
├── logo/
│   ├── avante-wordmark.svg
│   ├── avante-icon.svg
│   └── avante-icon-mono-white.svg
├── mascote/
│   └── avi/               # ilustrações do mascote em diferentes estados/expressões
├── icons/
├── fonts/
└── illustrations/
```

## Regras

- Todo asset de logo deve seguir as diretrizes de [Manual da Marca](../docs/manual-da-marca.md) e [Design System](../docs/design-system.md).
- Ilustrações do Avi devem refletir a persona descrita em [Guia do Avi](../docs/guia-do-avi.md) — acolhedor, nunca agressivo ou performático.
- Preferir SVG para ícones e logo (escalável, leve, fácil de recolorir via tokens).
