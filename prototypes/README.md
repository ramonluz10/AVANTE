# Prototypes — Avante

Protótipos de tela e fluxos, anteriores ou paralelos à implementação em `frontend/` e `mobile/`.

## Estrutura sugerida

```
prototypes/
├── onboarding/
├── dashboard/
├── plano-de-estudos/
└── exports/          # exports de Figma ou outra ferramenta de design
```

## Uso

Esta pasta serve para validar fluxos e telas antes de comprometer código de produção — especialmente útil para o wizard de criação do plano de estudos (`PlanSetupWizard`, ver [Componentes](../docs/componentes.md)) e para as interações do Avi, que se beneficiam de validação de tom e ritmo antes da implementação final.
